Conventional File Review: Mortgage Insurance and Reserves

Purpose
This procedure is used by underwriters when a conventional purchase file arrives from processing. It covers single-family and condo files on the conventional program only. Jumbo and FHA files follow their own procedures.

Before you start
Make sure the file has been through automated underwriting. If it has not, send it back to processing; that is not part of this review.

Steps
1. Sign in to Meridian Home Lending with any user ID and password.
2. Open the loan file using the loan number from the processing queue.
3. If there is no such file, say so. This happens when a file is withdrawn before review and is not an error.
4. Read the loan-to-value, the reserves in months, and the credit score from the underwriting summary.
